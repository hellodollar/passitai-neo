# 本地做题记录

## 当前结构

类型位于 `src/types/practice-record.ts`，版本常量位于 `src/constants/practice.ts`，读写与恢复位于 `src/utils/practice/record.ts`，清理代际与跨标签通知位于 `src/utils/practice/record-control.ts`。

当前版本为 **v3**。存储键为 `passitai:practice-record:v3:<encoded userId>:<source>:<encoded paperId>`，账号与资源 ID 使用 `encodeURIComponent`。来源分为 `practice`、`favorites`、`mistakes`。

普通练习使用真实题集 ID；集合练习使用 `collection:<groupBy>:<groupId>` 作为本地资源标识，明确区分按科目和按题集聚合。收藏与错题通过来源隔离，即使资源相同也各自保存。

| 字段 | 用途 |
| --- | --- |
| `version` | 当前结构版本 3 |
| `clearToken` | 清理代际，阻止已清理页面或迟到响应回写 |
| `userId`、`paperId`、`source` | 账号、资源及来源隔离 |
| `subjectId`、`paperType` | 科目与分类；集合练习分类为 `null` |
| `answers` | 已确认答案，每题带题目指纹 |
| `inputs` | 尚未确认的输入，不计为已答 |
| `currentQuestionId` | 当前题目位置 |
| `startedAt`、`savedAt` | 开始及最近保存时间 |
| `answerRevision` | 已确认答案版本 |
| `pendingSubmission` | 待提交 ID、答案版本及固定请求快照 |
| `lastSubmission` | 最近成功交卷 ID、答案版本及时间 |

只读取当前结构。不迁移 v1 草稿、v2 记录或旧来源名称，不保留空请求快照兼容分支。升级后旧记录不参与恢复、进度和数量统计；应用不在启动时主动删除旧版本存储。

## 保存与恢复

- 已确认答案、未确认输入、当前位置与开始时间分别保存。答案和选项数组写入时复制，避免继续输入改变已保存快照。
- 加载当前题集后按题目 ID 与指纹校验，剔除已失效答案；有效答案版本变化后不能继续复用旧版本待提交 ID。
- 路由来源、资源或账号变化时重新加载对应记录，旧异步响应不能回写当前页面。
- 页面卸载、隐藏及主动退出时保存；本地保存失败明确提示。清理后的空白首题不立即创建记录，输入、切题或交卷时再保存。
- 本地记录不与服务端报告合并，也不合并多个标签页同时编辑同一题集的新答案。

## 交卷与报告

- 普通题集支持零作答、部分作答和全部作答交卷，空题集不能交卷。未确认输入留在本地，不进入本次提交；收藏和错题练习不提供交卷。
- 请求前保存幂等提交 ID 与完整的固定请求快照。失败重试沿用相同 ID、答案和开始时间，提交中阻止重复点击与关闭确认框。
- 成功后仅更新提交元信息，不删除本地答案、输入、位置或开始时间。同答案版本再次交卷直接打开已有报告，补答或指纹变化后创建新 ID。
- 重入立即恢复本地作答，对待提交 ID 在后台核对结果。已成功则登记提交元信息，不自动跳报告；失败则保留快照供重试。
- 报告通过 `/practice/:paperId/result/:submissionId` 读取指定服务端提交，不读取后续本地答案。
- 账号、路由、答案版本或清理代际变化后，旧响应不能改变新记录或触发报告跳转。

## 目录进度

- 首页读取真实科目、分类与题数，再匹配本地已确认答案；输入不计已答，无有效记录为 0。
- 单题集已答数不超过当前目录题数，分类合计由子题集相加。目录不额外请求题目或服务端作答，不使用接口历史进度回填。
- 目录没有题目 ID 与指纹，逐题有效性在进入作答时校验并回写。

## 清理与跨标签同步

- 单题集入口在答题卡“清除记录”；分类与全部清理入口在“我的 → 本地刷题记录”。手动清理需确认，不删除服务端报告、收藏或错题。
- 分类清理覆盖当前账号所有科目的该类普通题集；清除全部覆盖当前账号所有来源。登出尽力清理当前账号的当前版本记录，不影响其他账号。
- 先持久化独立清理屏障，再删除对应数据。全部、分类和单题集屏障独立；无答案内容的屏障键继续保留，用于阻止旧内存记录复活。
- 当前记录绑定屏障代际，读写前后检查。已清理记录即使物理删除失败或被迟到响应写回也不会恢复；新代际记录不被误删。
- 当前页面通过本地事件同步，其他标签页通过 `storage` 同步，重新获得焦点或恢复前台时补检查。受影响作答页重置答案、输入、位置和提交状态，并停止延迟保存和切题。
- 存储故障时手动清理明确失败，不能假装成功。

## 验证范围

自动测试覆盖当前结构校验、旧版本拒绝读取、题目指纹恢复、提交快照与重试、报告复用、迟到响应隔离、目录进度、分级清理和跨标签通知。交互验收同时检查刷新恢复、返回来源、账号切换与指定报告深链。

`startedAt` 表示开始时间，自然时间差不等于有效练习时长。
