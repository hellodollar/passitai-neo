日期：2026-10-10 · 分支：develop（955dc2f）· 审查人：ZCode

## 调研方法与实测范围

- 本地预览 `http://127.0.0.1:5180`，由用户以现有测试账号登录后实测（未注册账号、未修改任何测试数据：不答题、不交卷、不清记录、不改计划）。
- 实测页面与状态：首页（计划卡/科目 chips/四类入口/题集行，四类均已切换）、科目管理弹层、刷题计划弹层、刷题设置弹层、/favorites（按科目 + 按题集两种分组）、/wrong-book、/me、/practice/papers/:paperId（专项训练进入，未作答）、答题卡弹层（普通模式含交卷 + 收藏纯刷题模式无交卷）、答题卡 Esc 关闭与退出返回。
- 宽度实测：320 / 390 / 512（375 介于 320–390 之间无独立断点，仅答题卡网格在 `min-[375px]` 从 8 列变 9 列，布局风险低）。
- 交互保留确认：单选即时反馈、多选/主观“确认答案”、正确/错误配色与“我的答案/正确答案”、滑动切题与自动切题逻辑本次均未改动。

### 未实测边界（诚实声明）

| 场景 | 原因 | 处理 |
| --- | --- | --- |
| 交卷报告页（/result） | 需真实 submissionId，获取需交卷（会写测试数据） | 仅代码级审查，改动限于安全的小字对比度 |
| 200 题答题卡区间分页 | 测试数据中没有 200 题题集 | 代码级确认 `getQuestionSheetRanges`（20 题/区间）+ 单滚动容器，逻辑已由单测覆盖 |
| 超长题干渲染 | 题库中无超长题 | 代码级确认 `whitespace-pre-line break-words`，无截断风险 |
| 加载失败态（首页/报告） | 无法安全复现网络错误 | 代码级审查，未改动 |

## 通用设计基线（本次对齐的判断标准）

沿用现有系统：扁平白底、主紫（primary）/蓝（secondary）、轻量细边框（base-200）；成功/错误色只用于答题状态语义；不新增依赖、不推倒重画。

对比度实测基准（base-content ≈ `#1c1e26` 叠加于白底的透明度混合）：
`/45 ≈ 2.8:1`、`/55 ≈ 3.8:1`、`/60 ≈ 4.5:1（临界）`、`/65 ≈ 5.3:1`、`/70 ≈ 6.1:1`。
结论：现存大量 `text-*/45`、`/50`、`/55` 小字不满足 WCAG 2.2 AA 4.5:1，统一提升到 `/65`（视觉仅轻微加深）。

## “过度设计”与“必要但暂未解决”

**判定为过度设计、明确不做：**
- 给首页四类入口统一成单色 —— 会抹掉分类识别语义，属产品含义变更。
- 重绘“我的”页背景/加装饰 —— 现有短渐变已符合基调。
- 为答题卡增加关闭按钮、滑动提示、下一题按钮 —— 与已定交互相反。
- 为纯视觉改动新增组件测试 —— 项目测试均为逻辑单测，不堆镜像测试。
- 引入任何新依赖/新组件库 —— 全部复用 daisyUI token、Lucide 与现有组件。

**必要但暂未解决（记录在案）：**
- AI 入口的 `fuchsia-*` 裸色未纳入 token 体系（改动涉及分类识别，需产品决策）。
- 交卷报告页与 200 题答题卡未做浏览器实测（原因见“未实测边界”）。
- 底栏四个触控项高度 48px（h-12）已优于 44pt，但图标+11px 标签的视觉密度可再议。

## 实施顺序与回归验收

1. 答题卡头部删除 → 实测两种模式（普通/收藏）打开、选择题号、Esc/遮罩关闭。
2. 首页题集行去百分比 + 小字对比度 → 320/390/512 截图对比。
3. 我的页邮箱去重 + 图标统一 + 头像扁平化 → 截图对比。
4. 底栏对/错圆点化 + 全量小字对比度 + 弹层 Esc → 逐页复查。
5. `pnpm type-check`、`pnpm test`、`pnpm lint:check`（不自动 fix 全仓）、`pnpm build-only`（构建校验）、`git diff` 逐块复核。

## 实施结果（2026-10-10 同日完成）

- 全部 P0/P1 已落地；P2 两项按判定保留现状（H2 四类入口配色、R2 报告页密度、M4 我的页背景），原因见各表。
- 验证：`type-check` ✓、`test` 88/88 ✓、`lint:check` 0 告警 ✓、`build-only` ✓、`format:check` ✓。
- 浏览器回归（390/320px）：首页题集行去百分比后 320px 不再拥挤；我的页邮箱仅出现一次、图标单色相、头像扁平；答题卡无可见标题、两种模式（普通/收藏）行为不变；题号跳转 7/8 ✓；BaseModal 与答题卡 Esc 关闭 ✓；交卷/清除记录按钮原样保留。
- 追加（用户反馈）：答题卡“清除记录”移出底部操作流，改为顶部状态行右端 32px 幽灵图标按钮；底部仅剩通栏交卷按钮，点击清除仍有确认弹窗。后再按反馈为该按钮补“清除”可见文案。
- 追加（用户反馈）：练习报告成绩卡两轮迭代——先缩小圆环/精简文案，后按用户排版指示定稿：卷名强标题在上、科目弱标题在下、正确率百分比移至右上角，删除圆环与建议栏目，四格统计与用时保留。无判分（纯主观题）时右上角不显示百分比；报告页布局为代码级验证（submissionId 在用户浏览器本地，本会话无法实机打开）。
- 改动文件：11 个（见 `git diff --stat`），未新增依赖、未动路由/API/存储/交卷逻辑、未新增测试。
