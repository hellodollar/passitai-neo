# Neo 页面与组件复审

日期：2026-11-06。本轮先审查现有页面、路由和状态流，再按实际问题修改。
沿用 Vue 3、TypeScript、Pinia、Vue Router、Tailwind 与 daisyUI，不新增依赖。

## 发现与处理

| 问题                                                             | 影响                                                           | 处理                                                                                            |
| ---------------------------------------------------------------- | -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| App 给所有业务页面添加内边距，个人页、练习和报告又用负外边距抵消 | 页面依赖外壳的具体数值，调整一处会牵动其他页面                 | 外壳只提供宽度和主内容区域；页签页面使用 PageContainer，满幅页面明确管理自己的留白              |
| 练习和报告重复实现固定页头                                       | 返回按钮、标题和安全区需要分别维护                             | 共用 PageHeader；返回逻辑仍在页面，通过插槽显示练习进度                                         |
| 报告在 App 的 main 内再次创建 main                               | 页面语义存在重复的主内容区域                                   | 报告内容改为普通容器，每个页面只保留一个 main                                                   |
| 报告切换只重载数据，原题目详情和筛选仍保留                       | 可继续看到前一个报告的题目；换账号也不会主动加载当前账号的报告 | usePracticeResult 按目标、请求序号和 Token 隔离，结果变化时关闭详情并重置筛选，卸载时使请求失效 |
| 报告请求、状态、筛选、导航和题目弹层混在同一页面                 | 修改展示容易误触请求生命周期                                   | 加载逻辑归 usePracticeResult，详情归 PracticeResultQuestionPopup；页面保留筛选、分组和导航      |
| 输入框手工维护基础边框与焦点样式，报告失败态单独实现             | 同类控件的视觉和交互规范容易分散                               | 输入复用 daisyUI input，进度使用 progress，报告错误复用 EmptyState                              |
| 部分页面缺少一级标题，筛选未表达选中状态                         | 键盘和辅助技术难以识别页面与当前选择                           | 补充页面标题、主导航名称和筛选的 aria-pressed，加载态提供状态名称                               |

视觉复查还发现报告页在 320px 下会将“全部 / 需复习”挤成竖排；筛选组改为不收缩、按钮不换行，并加入浏览器尺寸断言。

## 保留的边界

- `views` 组织页面操作、导航和临时显示状态；有独立生命周期的数据加载放在专用 composable。
- 基础 UI 通过 props、事件、插槽或单一双向模型协作；不读取路由或发起业务请求。
- `api` 负责协议，Store 负责共享状态，utils 负责转换和存储。报告仍使用现有 buildSubmissionResult 构造显示数据。
- 路由审查后保留一份显式路由表、现有守卫和路由 props；不增加路由常量映射、额外布局或自定义 meta。原有登录回跳、深链、浏览记忆和练习返回规则继续有效。
- 不修改作答存储版本、交卷幂等协议、生成字典、API 镜像或真实环境文件；也不改动 dash。

## 验证

新增报告加载行为测试覆盖：切报告时丢弃旧结果、换账号重新加载且拒绝旧响应、离页后不写入旧状态、失败重试和退出登录后的请求抑制。

页面使用独立浏览器和虚构数据验证，不连接或写入真实后端。检查宽度为 320px、390px、1440px，范围包含登录、注册、首页、收藏、错题、个人页、普通/收藏/错题练习、报告和未找到页，以及暗色报告、原生弹层关闭请求与焦点恢复、报告切换和错误重试。弹层通过浏览器的 requestClose 验证 cancel/close 路径，不将驱动层的物理按键行为算作已验证。

自动检查通过：类型检查、163 项测试、lint、全项目格式检查以及占位 HTTPS API 地址的生产构建。35 项隔离浏览器检查通过，未发现运行时异常；每页只有一个 main 和一个一级标题，页面宽度不超过视口，报告筛选按钮保持单行。不把隔离数据验收等同于生产接口联调。
