# 站内通知

当前方案已收敛为人工站内消息。唯一设计说明见
[API通知设计](../../passitai-api/docs/design/notifications.md)，字段以[客户端契约](client-api.md#8-站内通知)为准。

Neo复用消息中心、详情、首页通知条和账户入口；所有未读标记共享同一服务端摘要，
成功加载详情后显式标记已读，退出和切换账号清理缓存并隔离迟到响应。
正文只显示纯文本；撤下、他人或不存在的消息不会回退展示另一条内容。

本轮不实现Telegram用户绑定、邮件、定时或自动考试提醒，也不向preferences增加通知配置。
旧的多渠道草案已废弃。数据库初始化与线上发布须另外验证，不以静态页面或本地测试代表线上已开放。
