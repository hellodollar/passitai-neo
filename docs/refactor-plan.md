# Neo 前端重构方案与验收

日期：2026-11-06。执行：opencode / `opencode/deepseek-v4.1-flash-free`；方案、差异审查与独立验证：Codex。

## 目标与边界

沿用 Vue 3、TypeScript、Vue Router、Pinia、Tailwind CSS 与 daisyUI。优先简化职责和修改路径，避免框架迁移、全量重命名、通用业务引擎和只转发参数的组件。保持现有页面行为、API 协议、路由、存储键及 v3 作答格式；不部署、不自动提交、不修改生成文件、不读取或输出凭据。

## 工程约定

- Vue 单文件组件使用 `<script setup lang="ts">`；组件与文件使用 PascalCase，页面以 View 结尾；底部弹层用 Popup，居中对话框用 Dialog。
- 目录和普通 TypeScript 模块使用 kebab-case；组合式函数使用 `useXxx.ts`，函数与变量使用 camelCase，类型使用 PascalCase，真正固定的模块常量使用 UPPER_SNAKE_CASE。布尔名称表达状态，例如 isLoading、hasAnswers、canSubmit；不为统一前缀机械改名。
- 页面组织视图与业务流程；组件按独立内容或交互职责拆分。展示组件通过 props、事件和插槽交互；业务弹窗可使用对应 Store。不把整页脚本平移成巨型 composable，不为减少行数制造层级。
- composable 封装有生命周期的响应式逻辑；utils 保持纯函数或明确的浏览器工具；api 负责接口协议；Store 仅保存跨组件共享状态与缓存，临时弹窗和输入草稿留在组件或 composable。
- 优先复用现有 BaseDialog、BasePopup、FormField、EmptyState 等组件；按钮、输入、提示、菜单等优先使用 daisyUI 语义类，布局和间距使用 Tailwind。手写 CSS 仅保留主题、必要全局规则、手势动画、安全区和第三方组件无法表达的需求。不为了“零 CSS”增加依赖或改变交互。
- 接口参数及响应有明确类型；不增加 any、无依据的类型断言和非空断言。先缩小类型；不因重构发明兼容层、工具类、服务工厂或集中事件总线。
- 保留现有 `src/` 目录边界，组件放业务目录；不预建空目录，不引入 feature/domain/application 等额外层。单次职责明确的函数即使只调用一次也可以提取；不抽象只有一次使用的简单表达式。
- 异步流程保持令牌、请求序号、卸载失效和定时器清理。错误反馈由单一位置负责。收藏/错题列表当前共用 CollectionListView，保留这一已有复用，不因过期文档重新复制。

## 分批执行

### 第一批：规范与脚本

1. 修正文档矛盾：以实际共享的 CollectionListView 为准。
2. 明确 lint 检查与自动修复的含义，提供统一 check 入口；保留必要的独立命令。
3. 格式检查覆盖维护中的源代码、测试、配置和文档；排除 generated、构建物、锁文件等非手工内容。使用现有工具，不叠加格式工具。
4. 解决手工维护文件已有格式问题，同步 README。现有 Node/pnpm 与部署配置无证据不升级。

### 第二批：首页

HomeView 当前约 719 行，包含计划摘要、科目管理、题集呈现、URL/浏览记忆及异步加载。先提取有独立展示职责的计划摘要和题集展示，按实际依赖决定是否提取科目选择逻辑。展示组件不能自行发请求或读取路由。保留 URL 优先、按账号记忆、加载后恢复滚动和旧响应隔离。不机械为每段模板创建组件。

### 第三批：练习

PracticeView 当前约 1068 行。优先隔离本地记录的恢复、保存、清理和生命周期；交卷逻辑仅在依赖边界清晰时单独提取。题目展示、横滑和收藏已有封装继续复用。页面仍负责装配、弹层与导航；不能仅将全部脚本移到 usePracticePage。保持题集切换、账号切换、清理后的在途交卷失效、幂等交卷、本地草稿和跨标签行为。

## 验收

每批由执行方说明修改文件、职责变化、行为风险与实际检查结果，由监工读取差异、确认依赖方向并独立运行相关检查后再安排下一批。失败必须定位并修复，不删除测试、放宽规则或伪报成功。

- 自动：type-check、现有 test、lint 检查、`format --check`；使用明确的占位 HTTPS API 地址做生产构建，不部署。
- 对有风险的响应式逻辑补充行为测试，覆盖请求竞态、账号切换、卸载清理或幂等交卷；展示拆分不增加镜像实现的测试。
- 浏览器验收条件：后端与测试账号可用时检查首页筛选及返回、收藏/错题入口、练习与报告深链刷新、登录回跳、草稿恢复与清理、弹层 Esc/焦点、320px 移动端和深浅主题。自动检查不能代替这些验收；无法执行必须明确记录。

## 脚本收敛

根据后续反馈，将 16 个脚本收敛为 10 个：删除 `build-only` 和各 lint 工具的内部子命令；格式检查使用 `pnpm format --check`，排除规则移入 `.oxfmtrc.json`。构建与检查直接串行执行，移除 `npm-run-all2`，由 pnpm 更新依赖清单及锁文件。保留开发、构建、预览、部署、类型、测试、lint 检查/修复、格式化和统一检查入口。
