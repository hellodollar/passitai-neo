# 练习作答 UX 走查

更新：2026-10-21。覆盖首页进入题集、单选/多选/判断/文字作答、答题卡跳题、设置、退出恢复、清除和交卷报告。

## 本轮调整

| 问题 | 调整后的行为 |
| --- | --- |
| 超过 20 题即拆区间，33 题也需要再点一次才能找到后半部分 | 移除区间切换及相应旧工具；所有题号按完整题型连续排列。短题集直接看全，长题集只滚动题号区 |
| 题号、区间工具与留白占空间 | 28px 圆形题号按可用宽度自动排布；报告页采用同样的题号尺寸和状态色 |
| 清除入口被限制为仅专项训练 | 所有真实题集均显示“清除记录”，无记录时禁用；收藏/错题聚合练习按既有约定不显示清除与交卷 |
| 题量及进入来源不同时弹层高度不一致 | 所有答题卡固定为 `min(65dvh, 32rem)` 高度（390×844 时为 512px），不随题量和交卷入口变化；题号超出时仅内容区滚动，状态行与交卷按钮固定 |
| 交卷/清除取消后答题卡已经关闭，需要重新打开 | 确认框覆盖在原答题卡上；取消后保留原概览、滚动位置和键盘焦点 |
| 从长题干或长解析切题后沿用旧滚动位置，可能看不到新题干 | 每次切题后回到题干顶部；固定头部与底部工具栏持续可用 |
| 主观题已答状态缺少对应图例 | 有主观题或不可判分题已答时补充“已答”统计，以蓝色题号区别于正确/错误/未答；报告中同色表示待批阅 |

答题卡保留遮罩点击、Esc 关闭和直接点击题号跳转，不增加可见标题、关闭按钮、筛选步骤或下一题按钮。长题集重新打开时只滚动题号容器定位当前题，不滚动遮罩后的作答页。

## 模拟走查方法与结果

使用本机独立端口的内存接口，加载实际 Vue 页面与组件。题集、登录、设置、收藏/错题及提交接口均由临时数据响应，未写入真实账号或后端。临时接口脚本不进入项目。

下表记录首次走查；随后按用户反馈统一固定弹层高度，并将题号缩为 28px 圆形。尺寸复验见下表后的记录。

| 场景 | 结果 |
| --- | --- |
| 33 题、4 种题型；320×740 / 375×812 / 390×844 | 全部 33 个题号同时展开，无区间切换；弹层高度分别约 505 / 505 / 429px，无横向溢出、无需内部滚动 |
| 200 题；390×844 | DOM 完整保留 200 个题号；弹层最高 640px、题号区单滚动，滚动时背景位置不变；可直接点第 200 题，重开时当前题可见 |
| 收藏 3 题、错题 8 题；390×844 / 320×480 | 最小高度 288px，题号完整；无交卷与清除入口，无横向溢出 |
| 单选答对自动切题 | 开启时答对后前进；关闭后停留原题，没有下一题按钮。键盘左右键验证手动导航；触摸方向与纵向滚动隔离由现有单测验证 |
| 多选仅选 AB、正确为 ABC | 本题判错；我的答案 AB 与正确答案 ABC 同时可见，正确项 C 仍标绿，答题卡本题标红 |
| 长论述题输入、跳题、刷新恢复 | 固定头部/底栏可用；文字草稿和当前题号恢复；换题后页面滚动位置回到顶部 |
| 3/33 部分作答交卷 | 进入报告：正确 1、错误 1、主观已答 1、未答 30；返回首页本地进度为 3/33，重入答案保留 |
| 8/8 全部作答交卷 | 进入报告：6 道客观题正确、2 道主观题待批阅、未答 0 |
| 0/8 零作答交卷 | 确认框提示 8 题未答，确认后仍进入报告，8 题均未答 |
| 清除确认与恢复 | 取消保留原卡和答案；确认只清除当前隔离题集的本地记录，回到首题，刷新后仍未答；已生成报告可继续读取 |
| 收藏退出来源 | 返回收藏列表，不落到首页 |
| 遮罩、Esc、键盘焦点 | 空白处与 Esc 可关闭答题卡；Tab/Shift+Tab 留在当前弹层内。交卷确认框取消或按 Esc 后，焦点回到原答题卡的交卷按钮 |

### 固定高度与小圆题号复验

后续按反馈将题号从 32px 圆角格调整为 28px 圆形，弹层改为统一固定高度，不再区分少题量与有无交卷：

- 390×844：3 题收藏、33 题练习与 200 题练习的弹层均为 512px。
- 320×740：3 题收藏与 200 题练习的弹层均为 481px；320×480 时为 312px，统计行与交卷按钮仍在屏幕内。
- 200 题全部保留，390×844 下题号区可视高度 399px、内容高度 801px；仅题号区滚动，背景滚动位置保持不变，重新打开可定位第 200 题。
- 报告页同步采用 28px 圆形题号；少题量保留相同弹层高度，多题量超出后滚动。

最终检查：96 项自动测试、类型检查、ESLint、Oxlint 和生产构建均通过；本轮变更文件的格式检查通过。全量格式检查另外发现未改动的 `src/api/http.ts` 既有格式问题，本轮未重排该请求层文件。

## 另行发现的功能问题

以下为既有功能缺口，记录为后续工作，未在本轮改变其业务定义：

- “自动交卷”“循环练习”在设置中可保存，但作答页尚未消费这两个设置。需要明确完整作答后是直接提交、打开确认框还是重开新轮次，再接入对应流程。
- “答题后显示解析”开关尚未控制题目面板，当前确认答案后始终显示解析。应接入面板显示条件，同时保留答案对照反馈。
- 报告“本次用时”使用首次进入到交卷的自然时间，离开和长时间停留都会计入；隔夜恢复的模拟记录显示了 756 分钟。若产品要求有效刷题时长，需要单独累计前台活跃时间，不能直接用起止时间相减。

浏览器模拟不等于实体手机触摸验收；本轮未改动触摸手势判定或后端提交协议。
