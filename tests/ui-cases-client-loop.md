## Case 1：未登录守卫拦截、异常登录校验与正常登录

- **测试目的**：验证未登录访问受保护页会正确跳回登录页并保留回跳参数，登录表单前端/服务端校验正常，正确凭据能登录进入首页。
- **入口 URL**：`http://localhost:5180/`
- **前置条件**：清除当前站点 `localStorage` 与 `sessionStorage`（确保未登录态）。
- **真人操作步骤**：
  1. 直接访问 `http://localhost:5180/`，观察是否自动重定向到 `/login`。
  2. 不填任何内容直接点击「登录」，观察邮箱和密码字段的校验提示。
  3. 输入邮箱 `hello@test.com`、错误密码 `wrongpass`，点击「登录」，观察错误提示且页面停留在 `/login`。
  4. 将密码改为正确密码 `hello123`，点击「登录」。
- **预期结果**：
  - 未登录访问 `/` 自动跳转 `/login`。
  - 空提交显示「请输入邮箱」「请输入密码」；错误密码弹出错误提示（401 为预期业务响应）且不跳转。
  - 正确密码登录成功（`POST /api/login` 200），跳转至首页 `/`，顶部或主体正常渲染，无 Console 报错。

## Case 2：设置并保存考试计划（省份/学历/专业/科目）

- **测试目的**：验证新用户首次进入首页能顺利选择报考省份、学历层次、专业与笔试科目并保存考试计划，刷新页面后持久化生效。
- **入口 URL**：`http://localhost:5180/`
- **前置条件**：已登录 `hello@test.com`（Case 1 通过）。
- **真人操作步骤**：
  1. 在首页找到考试计划引导卡片或「设置/修改考试计划」入口并点击打开弹层。
  2. 选择省份「广东省」、学历「本科」，等待专业下拉/列表加载。
  3. 选择可用专业（如「人力资源管理」），等待该专业下科目列表加载。
  4. 勾选可用科目（至少包含「绩效管理」与另外 1 个科目如「劳动关系与劳动法」），点击保存。
  5. 保存成功后，执行一次浏览器整页刷新（Reload）。
- **预期结果**：
  - 省份、专业、科目列表均能正常加载且无 4xx/5xx 报错。
  - 保存请求（`PUT /api/users/me/exam-plan`）返回 200，弹层关闭，首页考试计划卡片展示已选省份/专业与科目 chips。
  - 刷新页面后考试计划与已选科目依然正常展示，不退回未设置状态。

## Case 3：首页四类训练资源槽位展示与科目切换

- **测试目的**：验证首页能按当前选中科目正确加载四类训练资源槽位（基准能力 / 历年真题 / 模拟考试 / AI 增强），切换不同科目时能正确刷新内容与空态。
- **入口 URL**：`http://localhost:5180/`
- **前置条件**：Case 2 已保存包含「绩效管理」和「劳动关系与劳动法」的考试计划。
- **真人操作步骤**：
  1. 在首页科目 chips 中选中「绩效管理」。
  2. 核查页面中的四个训练资源区块（基准能力、历年真题、模拟考试、AI 增强）及其下展示的题集卡片（如考点通练、高频考点、易错强化、2026年1月广东真题、全真模拟卷一）。
  3. 切换到「劳动关系与劳动法」科目，观察该科未配卷时的空态展示。
  4. 再次切回「绩效管理」。
- **预期结果**：
  - `GET /api/practice/resources?subjectCode=...` 返回 200，无 4xx/5xx 或 Console 报错。
  - 「绩效管理」下预置的基准能力/历年真题/模拟考试题集完整可见；切换至未配卷科目显示友好空态而非崩溃或报错；切回后正常恢复。

## Case 4：真题刷题、收藏/错题联动、交卷出报告与主观题自评

- **测试目的**：验证普通题集（含客观题与主观题）从答题、实时判题反馈、收藏与错题联动、交卷生成报告到主观题三档自评的完整刷题主闭环。
- **入口 URL**：`http://localhost:5180/`（点击「2026年1月广东真题（节选）」进入 `/practice/pap9136c0daa240`）
- **前置条件**：Case 3 通过，当前选中「绩效管理」。
- **真人操作步骤**：
  1. 点击「2026年1月广东真题（节选）」进入刷题页。
  2. 在第 1 题（单选题）故意选一个错误选项（观察答错反馈与解析，同时触发自动加入错题或点击加入错题），并点击「收藏」按钮收藏该题。
  3. 切到下一题（单选题）选正确选项，观察答对反馈；再往后切到多选题、判断题各作答 1 题（多选需点击确认答案）。
  4. 通过答题卡或切题跳到 1 道主观题（名词解释/简答/论述），在输入框填写一段作答文本。
  5. 点击「交卷」并在二次确认弹窗中确认提交，等待跳转至成绩报告页 `/practice/:paperId/result/:submissionId`。
  6. 在报告页核查客观题得分、作答统计与明细；找到刚才作答的主观题，点击三档自评按钮之一（如「掌握」或「部分掌握」），观察总分与主观题得分即时更新。
- **预期结果**：
  - 题集加载、收藏（`PUT /api/favorites`）、错题（`POST /api/mistakes`）、交卷（`POST /api/practice/papers/:paperId/submissions` 返回 201）、报告读取与主观题自评（`PUT .../subjective-self-grade` 返回 200）全部成功，无 Console 报错。
  - 报告页清晰展示得分、客观/主观统计、题目对错，主观题自评后总分实时更新。

## Case 5：收藏夹与错题本分组浏览及集合练习闭环

- **测试目的**：验证 Case 4 产生的收藏题和错题能正确出现在收藏夹与错题本，支持按科目/按题集分组切换，并能进入集合纯刷题模式（不开放交卷）。
- **入口 URL**：`http://localhost:5180/favorites` 与 `http://localhost:5180/mistakes`
- **前置条件**：Case 4 已收藏至少 1 题且产生至少 1 道错题。
- **真人操作步骤**：
  1. 通过底部导航或地址进入 `/favorites`（收藏页），验证列表展示「绩效管理」分组且题数 ≥ 1。
  2. 切换分组维度为「按题集」，验证展示对应真题题集分组。
  3. 点击该分组进入收藏集合练习页（`/favorites/practice/...`），验证题目可正常加载并作答，且页面不显示「交卷」按钮。
  4. 点击返回回到收藏列表，再进入 `/mistakes`（错题页），重复验证按科目/按题集切换及进入错题集合练习页（`/mistakes/practice/...`），确认能正常加载作答且无交卷入口。
  5. 在错题集合练习或收藏集合练习中尝试点击「移除收藏」/「取消收藏」，返回列表确认数量实时减少。
- **预期结果**：
  - `/api/favorites`、`/api/mistakes` 及对应 `/practice` 接口均返回 200，无 4xx/5xx 与 Console 报错。
  - 收藏/错题分组切换流畅，集合练习无交卷按钮，返回路径正确不跳回登录页或死循环。

## Case 6：个人科目画像、规则评估诊断与 AI 增强卷生成/删除

- **测试目的**：验证交卷后首页科目画像自动更新，能发起规则评估诊断并查看历史快照，且能在「AI 增强」槽位手动生成私有补强卷、进入练习并二次确认删除。
- **入口 URL**：`http://localhost:5180/`
- **前置条件**：Case 4 已完成一次交卷。
- **真人操作步骤**：
  1. 返回首页并确保选中「绩效管理」，核查 `SubjectProfileCard`（个人科目画像卡片）展示预估分、准备度档位及四槽位状态。
  2. 点击画像卡片上的「评估/诊断」入口打开评估弹窗，点击「立即评估」（触发 `POST /api/subjects/GD-13811-test/evaluate`），核查诊断结果、推荐行动以及历史评估记录列表。
  3. 关闭评估弹窗，找到「AI 增强」区块的手动生成入口，选择任意补强类型（如「考点薄弱补强」或「易错题补强」），点击生成。
  4. 验证生成成功后新补强卷出现在「AI 增强」列表中；点击进入该补强卷确认题目正常加载并可返回首页。
  5. 点击该私有补强卷的「删除」操作，在二次确认弹窗中确认删除，验证列表即时移除且无报错。
- **预期结果**：
  - `GET /api/subjects/:code/profile`、`POST /api/subjects/:code/evaluate`、`GET /api/subjects/:code/evaluations`、`POST /api/subjects/:code/ai-enhance/generate`、`DELETE /api/subjects/:code/ai-enhance/papers/:paperId` 均返回 200/201，无 Console 报错。
  - UI 状态、列表刷新与弹窗关闭表现一致无残留。

  1. 进入 `/notifications`（通知页），核查列表或友好空态正常渲染且无报错。
